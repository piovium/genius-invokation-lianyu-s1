# 按轮次的玩家筛选排序

针对一系列轮次，收集这些轮次中所有已完成场次的对局结果（不计入统计的除外）。对于参与比赛的每位选手，计算如下指标：

- **参与局数**。
- **获胜局数**，prefer 管理员指定的结果，平局不计入胜利。
- **小分**： 玩家在这些对局所对阵过的所有对手，`所有对手胜局数之和/所有对手总参与局数之和`。如共参与了3个对局，玩家A对阵过B、C、D，B参与3场胜2场，C参与3场胜1场，D参与2场胜0场，小分为`(2+1+0)/(3+3+2)=0.375`。
- **小小分**： 玩家在这些对局中所对阵过的所有对手，这些人在这些对局中所对阵过的所有对手，`所有对手的所有对手胜局数之和/所有对手的所有对手总参与局数之和`。如工参与了3个对局，玩家A对阵过B、C、D，B对阵过A、E、F，C对阵过A、E、G，D对阵过A、H，则小小分为`AAAEEFGH的胜局数之和/AAAEEFGH的总参与局数之和`。

小分、小小分重复对手对局按每名对手一次。

将所有参与局数 > 0 的玩家筛选后，按 (获胜局数, 小分, 小小分) 降序排列。
