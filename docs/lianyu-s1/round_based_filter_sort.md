# 按场次的玩家筛选排序

针对一系列场次，收集这些场次中所有已完成盘次的结果。对于参与比赛的每位选手，计算如下指标：

- **参与盘数**。
- **获胜盘数**。
- **小分**： 玩家在这些盘次所对阵过的所有对手，`所有对手胜盘数之和/所有对手总参与盘数之和`。如共参与了3个盘次，玩家A对阵过B、C、D，B参与3盘胜2盘，C参与3盘胜1盘，D参与2盘胜0盘，小分为`(2+1+0)/(3+3+2)=0.375`。
- **小小分**： 玩家在这些盘次中所对阵过的所有对手，这些人在这些盘次中所对阵过的所有对手，`所有对手的所有对手胜盘数之和/所有对手的所有对手总参与盘数之和`。如工参与了3个盘次，玩家A对阵过B、C、D，B对阵过A、E、F，C对阵过A、E、G，D对阵过A、H，则小小分为`AAAEEFGH的胜盘数之和/AAAEEFGH的总参与盘数之和`。

小分、小小分重复对手盘次按每名对手一次。分母为 0 计分就是 0。

将所有参与盘数 > 0 的玩家筛选后，按 (获胜盘数, 小分, 小小分) 降序排列。
